Gradient–Momentum Based Microclimate Instability Detection
Using Spatial–Temporal Sensor Networks
IEEE Conference Paper · Chanthu S, Manpreet Kaur · Lovely Professional University
This paper proposes a lightweight and interpretable framework for detecting pre-event microclimate instability using distributed sensor networks. Unlike conventional approaches relying on absolute thresholds or late-stage event detection, the proposed GMS method analyzes spatial gradients, temporal momentum, duration, and neighbor influence — achieving higher accuracy and lower false alarm rates compared to both threshold-based and Z-score statistical baselines. The system is extended to N=40 nodes to validate scalability, maintaining stable O(N) complexity.
Framework contribution: A real-time simulation platform for analyzing microclimate instability in WSNs, supporting interactive experimentation with weight sensitivity, noise robustness testing, and multi-baseline comparison — all demonstrated live in this dashboard.
GMS Unified Score (Eq. 7) — core novelty
S_i(t) = w₁·|ΔT_i| + w₂·|M_i| + w₃·NIS_i + w₄·D_i
Default weights: w₁=0.35 · w₂=0.25 · w₃=0.20 · w₄=0.20  |  Classification: <0.25 Stable · 0.25–0.60 Mod · ≥0.60 High
Complexity: O(N·k)≈O(N) · Memory: O(k)/node · N=40 nodes validated
Baselines compared: Absolute threshold (T>26.5°C) · Z-score (|Z|>1.2) · Proposed GMS
Four Core Components
① Spatial Gradient [Eq. 2–3]
ΔT_ij(t) = T_i(t) − T_j(t)
Relative temperature difference between neighbors. Approximates ∇T(x,t)·d_ij. Detects localized variation invisible to absolute-value methods.
② Temporal Momentum [Eq. 4]
M_ij(t) = ΔT(t) − ΔT(t−1)
First-order temporal difference ≈ d(ΔT)/dt. Positive momentum = increasing instability → enables early detection before threshold crossings.
③ Duration / Persistence [Eq. 5]
D_i: counter if |ΔT| > θ
Low-pass temporal filter. Transient noise ε(t) dissipates; true instability persists. Demonstrated by noise experiment (toggle on Dashboard).
④ Neighbor Influence Score [Eq. 6]
NIS_i = (1/|N(i)|) Σ ΔT_ij
Mean gradient over neighbors N(i). Models spatial propagation. A node becomes influenced when its neighbors are unstable — captures spread dynamics.
Scalability & Robustness Notes
Scalability: Network extended from 12 to 40 nodes with randomized placement. Performance remains stable, supporting the O(N·k)≈O(N) complexity claim.
Noise robustness: Random noise ±0.5°C injected (toggle on Dashboard). GMS remains stable due to Duration (persistence filter) and NIS (spatial averaging). Absolute threshold exhibits increased false alarms under noise.
Weight sensitivity: Use the Dashboard sliders to vary w₁–w₄. Performance remains stable across weight variations, demonstrating model robustness.
Z-score baseline: Per-node statistical anomaly detector |Z|>1.2. Compared alongside absolute threshold in all metric panels.
